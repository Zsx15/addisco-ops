# Commandes utiles

## Installer dépendances

```bash
pip install -r requirements.txt
```

## Lancer Streamlit

```bash
streamlit run app.py
```

## Créer requirements

```bash
pip freeze > requirements.txt
```

## Exemple requirements de départ

```txt
streamlit
openai
python-dotenv
pandas
```

## Lancer tests plus tard

```bash
pytest
```
